TOOLBOX SFX — 137 Free Game Sound Effects
Arcade UI Forge   •   v1.0   •   FREE for commercial use

The everyday sounds almost every game needs, in one folder: menus,
footsteps, jumps, swings, guns, explosions, doors, pickups and magic.
Every sound was synthesized in code for this pack (no sample libraries),
peak-normalized and checked for clipping.

FORMATS
  WAV/<category>/   44.1 kHz, 16-bit stereo
  OGG/<category>/   same names, engine-ready Ogg Vorbis
  manifest.json     name, category and length of every sound

CATEGORIES (137)
  ui (22)          clicks x4, hovers, confirm, cancel, error, toggle on/off,
                   slider tick, notifications, popup open/close, purchase, typing
  footsteps (24)   grass, gravel, stone, wood, metal, snow — 4 variations each
  movement (8)     jump x2, land x2, slide, dash, ladder x2
  combat (22)      light/heavy swings, sword clashes, sword hits, punches,
                   shield blocks, bow draw, arrow shoot, arrow impact
  weapons (15)     pistol x2, shotgun x2, rifle single + burst, SMG burst,
                   reloads x2, shotgun pump, empty click, shell drops, lasers
  explosions (8)   small x2, medium x2, large x2, distant, debris
  world (18)       wood/metal doors open + close, locked door, chest, glass
                   break, wood break, metal clangs, splashes, bubbles, fire,
                   lever, switch
  pickups (12)     coins x3, gems x2, health, power-up, key, item, ammo,
                   level up, unlock
  magic (8)        cast, heal, fireball, ice, lightning, buff, teleport, shield

TIPS
  Randomize between the numbered variations (_01, _02 ...) and add a small
  random pitch shift (+/- 5%) so repeated sounds like footsteps stay natural.
